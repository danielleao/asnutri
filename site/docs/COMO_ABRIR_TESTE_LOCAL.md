# Pasta de teste local da AS Nutri

Abra o arquivo `index.html` desta pasta com duplo clique. O site abre no navegador sem precisar de servidor nem de comandos.

- Precisa de internet só para carregar as fontes (Playfair Display, DM Sans e Marck Script). Sem conexão, o navegador usa fontes parecidas.
- Os botões de WhatsApp, Instagram e e-mail funcionam normalmente.
- Não edite os arquivos desta pasta: ela é gerada a partir de `src/` com `pnpm run teste:local`.
