# Sistema AS Nutri (Python)

Reservado para o sistema de gestão da consultoria (multiusuário, relatórios e fichas técnicas).

Ainda não iniciado. Quando começar:

1. Criar o projeto Python nesta pasta (com `requirements.txt` ou `pyproject.toml`).
2. Criar um **novo serviço** na Railway, no mesmo projeto, ligado a este repositório com Root Directory `/sistema`.
3. Configurar **Watch Paths** nos dois serviços (`/site/**` e `/sistema/**`) para que um não faça redeploy quando só o outro mudar.
4. Banco de dados e segredos ficam em variáveis da Railway — nunca no repositório.

Antes de colocar código ou dados de clientes aqui, tornar o repositório privado no GitHub.
